# 全局 Agent 协作规范

本文件是跨项目共享的 agent 协作约定（pi 在 `~/.pi/agent/AGENTS.md` 全局加载）。项目级 `AGENTS.md` 只承载项目特有治理，不重复本文件的通用约定。

## 单一目的分支/PR

- 一个分支/PR 只做一件事（一个需求或一个独立变更）。多个需求拆多个分支，不得在一个分支上混叠多个需求，否则 review 范围和回滚都失去边界。

## 增量评审

- `code_reviewer` 以「本轮改动」为锚点，不无差别全量重扫整个工作树。
- review 范围 = 本轮 diff 的每个 hunk + 改动涉及符号（导出/类型/契约）在全仓库的存量引用点 + 改动触及的状态机/guard/版本绑定的相邻契约。
- 主动追踪影响面：对改动的导出符号、类型、契约做引用点排查（grep 调用方/import 点），逐一确认是否受改动影响；不要用「全量扫」代替「影响面追踪」。
- 行为层面的影响面由实现者自检的全量测试兜底，评审不重跑全量测试，除非怀疑测试本身。

## 增量提交基线

- `implementer` 在每轮评审通过后，把本轮改动本地 commit（不 push）作为下一轮评审的固定点；commit 前确认不含 secrets、生成物、临时 trace 或 session 状态。
