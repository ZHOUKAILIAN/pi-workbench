# Examples

这里只保存脱敏后的协作记录，用来回答：什么任务值得分派、prompt 实际如何写、子 agent 返回了什么证据、父 agent 如何处理冲突，以及最终结果是否通过验证。

每个案例至少包含：

- 原始目标的脱敏摘要；
- 使用的 agent / prompt / team recipe 及版本；
- 实际分派给子 agent 的 prompt；
- 子 agent 输出的必要证据摘要；
- 父 agent 的综合判断；
- 验证结果和复盘；
- 哪些内容因隐私或安全被移除。

禁止提交原始 session、token、cookie、账号、客户数据、内部链接和机器私有配置。
