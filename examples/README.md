# Examples

这里只保存脱敏后的真实协作记录，用来验证 agent role 和 workflow skill 是否真的改善交付。

每个案例至少记录：

- 原始目标的脱敏摘要；
- 使用的 agent role 与 workflow skill；
- 父 agent 实际分派的有界任务；
- 各阶段的必要证据与 verdict；
- 父 agent 如何处理冲突或返工；
- 最终验证结果与复盘；
- 因隐私或安全被移除的内容类型。

禁止提交原始 session、token、cookie、账号、客户数据、内部链接和机器私有配置。
